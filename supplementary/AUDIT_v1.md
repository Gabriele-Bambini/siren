# AUDIT of the v1.0 release (independent re-read, 2026-10-22)

Scope: scripts and manuscript of release v1.0 (`b39e705`..`2cf65a1`). Every finding cites file:line in
the v1.0 tree. Severity: **S1** invalidates a headline claim · **S2** weakens/biases a claim ·
**S3** hygiene / wording. Status is updated in place by later commits (never delete a finding).

| D1 | S1 | Enformer output bin is indexed as if the 896 output bins spanned the whole 196,608-bp input. Enformer returns only the central 114,688 bp (896×128 bp; 40,960 bp cropped on each side), so the correct bin is `(rel_pos − 40960)//128`; the code reads `rel_pos//128` and clips to 895, i.e. a bin ~320 bins (~41 kb) away from the TSS for central promoters. | `scripts/hpc_w3b_enformer.py:108`, `scripts/hpc_w3_enformer_probe.py:133` | C3 (title claim: "failure of sequence-model counterfactuals") | open → E3 |

| D3 | S1 | Reported bootstrap CI for the W3b increment, `[-0.2107, +0.133]`, does **not** contain the reported point estimate (`-0.2748`), and its upper bound lies above the pre-specified +0.02 benefit threshold. The bootstrap resamples 120 test rows with replacement and recomputes Spearman on duplicated rows with fixed predictions. | `results/w3b_summary.json` (HPC), `scripts/hpc_w3b_stats.py:46-53` | C3, abstract | open → E3 |

## What survives the audit (not affected by D1–D17 as written)
* Data harmonisation checks (label bit-identity, distance reconciliation, unit tests).
* The base-rate observation underlying C4 (96.7% of significant effects are repressions), which is a
  property of the benchmark labels and can be recomputed in one line. Novelty of C4 is checked in
  `LITERATURE_SURVEY.md`.
