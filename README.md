# SIREN — CRISPRi enhancer–gene baselines, LOCO reassessment and a corrected Enformer silencing analysis

Code, pre-specification, audit trail and machine-checked results for a re-analysis of the public
EPCrisprBenchmark K562 table (10,356 tested element–gene pairs).

[![CI](https://github.com/Gabriele-Bambini/siren-crispr-reference/actions/workflows/ci.yml/badge.svg)](https://github.com/Gabriele-Bambini/siren-crispr-reference/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

> **Status: v2 revision (branch `revision/hpc-repro`), not yet a release.** The v1.0 release made claims
> that an audit did not support ([`supplementary/AUDIT_v1.md`](supplementary/AUDIT_v1.md)); in particular its
> "failure of sequence-model counterfactuals" came from an output-bin indexing bug, and its "specificity
> wall" from applying K562 accessibility to other cell types. The v1.0 figures under `results/*.png|pdf`
> are kept only as an audit trail and are **retracted**.

**Headline (pre-specified, confirmed):** the corrected Enformer K562-CAGE silencing score adds information to distance + accessibility for pairs inside the model window, in LOCO evaluation and in a held-out confirmation planned before any held-out score was computed (PREREG A20, tag `prereg-v2-e8`).
Against a stronger, open rE2G-like baseline with K562 Hi-C contact and chromatin activity (PREREG A21, tag `prereg-v2-e9`) the LOCO gain is smaller but still pre-specified BENEFIT (+0.042), the contact feature fails its positive control (so "beyond 3D contact" is not claimed), and on the held-out screens (post hoc) the gain over that baseline is +0.007 (not detectable). The comparison with the published cross-validated rE2G predictions (Synapse, account needed) has not been run.

## What v2 reports (all numbers in [`paper/MANUSCRIPT.md`](paper/MANUSCRIPT.md), regenerated by the pipeline)
1. Unfitted log-distance reproduces the published AUPRC of the benchmark's distance baseline; gradient-boosted
   regression on distance + K562 ATAC is **below** it under leave-one-chromosome-out (LOCO) with
   cluster-bootstrap intervals; benchmark annotations and logistic regression are not detectably better.
2. No cross-context collapse where it can be tested (K562 held-out screens, WTC11); three held-out cell types are untestable. Transferred models are below unfitted distance in the target.
3. After correcting the Enformer indexing and track choice, the K562-CAGE silencing score adds to distance +
   accessibility for pairs inside the model window (pre-specified rule: BENEFIT against a weak regression
   baseline). Against unfitted distance the GBM combination is not detectably better; the score alone and
   logistic models with it are, in post-hoc contrasts. The v1.0 negative headline was an artefact (D19).
4. Constant-width conformal intervals are calibrated only on average; per-decile (Mondrian) intervals fix
   conditional coverage; conformal selection is inconclusive.
5. Method variants (ranking objectives, two-stage, uncertainty penalty, nested HPO, gene covariates) do not
   improve on the baseline.

Every analysis was pre-specified in [`supplementary/PREREG_v2.md`](supplementary/PREREG_v2.md) (git-committed; 19
dated amendments state whether results had been seen; no external timestamp yet). Novelty and rebranding were checked against
[`supplementary/LITERATURE_SURVEY.md`](supplementary/LITERATURE_SURVEY.md) (66 DOI-verified references).

## Reproduce
```bash
# local, no data needed (≈20 s): synthetic end-to-end smoke test and unit tests
python3 -m pip install -r requirements.txt
python3 scripts/demo_synthetic.py && python3 -m pytest tests -q

# full pipeline on a SLURM cluster with the raw benchmark data under $SIREN_ROOT/data/raw
bash hpc/setup_env.sh        # pinned virtualenv (hpc/requirements.lock.txt)
bash hpc/run_all.sh          # CPU pipeline (E1,E2,E4,E5,E6,E7) + GPU pipeline (Enformer E3)
python3 scripts/claims.py build render check   # results -> claims.json -> manuscript; fails on any mismatch
```
`SIREN_ROOT` (default `~/siren_hpc`) must contain `data/raw/` as fetched by the v1.0 preprocessing
(`scripts/hpc_preprocess.py`): EPCrisprBenchmark tables (EngreitzLab/CRISPR_comparison), ENCODE ATAC peaks
(ENCSR956DNB), hg38, GENCODE promoter table. Enformer weights are read from the Hugging Face cache
(`EleutherAI/enformer-official-rough`, offline at run time). Seeds, hyper-parameters and package versions are
fixed; `results/v2/env_freeze_*.txt` records the environment of each run.


## Limitations to keep in mind
One training cell type and one public table; labels depend on screen power; the effective sample is the number
of independent loci, not pairs; the Enformer analysis covers only pairs inside the model window and uses a
community port of the weights (fidelity-checked, not compared with the original implementation); several
analyses were added after earlier results were seen and are labelled post hoc in the manuscript and in PREREG
amendments A11–A19.
